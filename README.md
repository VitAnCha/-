# Проект Ануфриева В.С.
## Отток клиентов - одна из ключевых проблем банковского сектора: привлечение нового клиента обходится значительно дороже, чем удержание существующего. Анализ датасета Bank Customer Churn позволяет выявить закономерности ухода клиентов и выстроить проактивные меры удержания.
